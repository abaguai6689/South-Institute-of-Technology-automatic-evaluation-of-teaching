# 超星自动评教助手 v2.0

一个用于自动填写超星学习通评教系统的浏览器插件，支持批量一键评教。

## 🆕 版本 2.0 新功能

- ✅ **批量自动评教** - 在教师列表页面一键评教所有未评教师
- ✅ **完整自动化流程** - 自动填写 → 提交 → 确认 → 返回 → 刷新 → 继续下一个
- ✅ **实时进度显示** - 显示当前评教进度和剩余教师数量
- ✅ **智能延时控制** - 可设置评教间隔，避免操作过快
- ✅ **随时可停止** - 批量评教过程中可随时停止

## 功能特点

- ✅ **一键自动填写** - 自动识别所有打分题并填写预设分数
- ✅ **智能分值控制** - 根据每道题的分值上限自动调整分数，不会超出限制
- ✅ **简答题自动填写** - 评价与建议类题目自动填写"无"
- ✅ **实时预览** - 显示评分配置，清楚知道每道题将填写多少分
- ✅ **浮动控制面板** - 在评教页面显示可拖动的控制面板，操作便捷
- ✅ **安全可靠** - 只在超星评教页面运行，不会影响其他网站

## 安装方法

### Chrome / Edge 浏览器

1. 下载插件文件夹 `auto-evaluate-extension`
2. 打开浏览器扩展管理页面：
   - Chrome: 地址栏输入 `chrome://extensions/`
   - Edge: 地址栏输入 `edge://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择 `auto-evaluate-extension` 文件夹
6. 安装成功！

## 使用方法

### 方法一：单个评教（评教表单页面）

1. 登录超星学习通，进入评教入口页面
2. 点击需要评价的课程「评价」按钮
3. 在评教页面，你会看到右上角出现「📝 自动评教助手」浮动面板
4. 点击「一键自动填写」按钮仅填写表单
5. 或点击「自动填写并提交」按钮完成完整流程
6. 检查填写内容是否正确
7. 点击页面底部的「提交」按钮完成评教

### 方法二：批量评教（教师列表页面）⭐推荐

1. 登录超星学习通，进入评教入口页面（教师列表）
2. 页面右上角会出现「🚀 批量自动评教」浮动面板
3. 点击「开始全部评教」按钮
4. 插件会自动：
   - 点击第一个未评教师的「评价」按钮
   - 自动填写所有题目
   - 点击「提交」按钮
   - 点击确认对话框的「确定」
   - 点击「返回」回到列表
   - 刷新页面获取最新状态
   - 继续下一个未评教师
5. 直到所有教师评教完成

### 使用 Popup 窗口

1. 点击浏览器工具栏上的插件图标
2. 查看当前页面状态和题目数量
3. 在评教页面：点击「一键自动填写」或「自动填写并提交」
4. 在教师列表页面：点击「开始全部评教」启动批量模式

## 批量评教控制

- **开始**：点击「开始全部评教」按钮
- **停止**：点击「停止」按钮可随时中断
- **延时**：可勾选「评教间隔延时」，每评完一个教师后等待3秒再继续
- **进度**：实时显示当前进度（已完成/总数）

## 注意事项

1. **请在填写后仔细检查** - 虽然插件会自动填写，但建议提交前人工确认一遍
2. **分值上限保护** - 插件会自动检测每道题的分值上限，确保不会填写超出范围的分数
3. **页面识别** - 插件只在超星评教相关页面生效：
   - 评教表单页面：`newes.chaoxing.com/pj/newesReception/questionnaireInfo`
   - 教师列表页面：`newes.chaoxing.com/pj/frontv2/whatIEvaluatedDetails`
4. **网络延迟** - 如果页面加载较慢，请等待页面完全加载后再使用插件
5. **批量模式** - 建议在开始批量评教前，先手动评教一个教师，确认流程正常

## 技术说明

- 使用 Manifest V3 标准开发
- 支持 Chrome、Edge 等 Chromium 内核浏览器
- 采用原生 JavaScript，无需额外依赖
- 通过 content script 注入页面，与页面元素直接交互
- 使用 background script 管理批量评教状态
